# Video course

A narrated walkthrough of this repository in **36 chapters**, built from code. **Every terminal in the video shows
real output**: the commands were recorded while the lessons ran (`tests/mdrun.py --record`): each application on
Docker, the platform on Docker Compose and on a kind cluster, the troubleshooting labs and the capstone. Code panels
show the real files of the repository. Nothing on screen is typed by hand.

## Two final versions

| File | Picture | Sound |
|---|---|---|
| `out/multi-stack-kubernetes-full.mp4` | the edited video | narration (cleaned up), original background music ducked under the voice, subtle sound effects; -14 LUFS, true peak below -1 dBTP |
| `out/multi-stack-kubernetes-silent.mp4` | **the identical picture stream** (copied from the same encode with `-c:v copy`: the same cuts, transitions, animations, zooms and text, frame for frame) | none (no audio track) |

Production touches, each with a purpose: an animated title and end card, chapter titles and a progress bar, elements
that ease in as they are explained, **terminal zooms** onto the lines being explained, highlighted lines in code panels,
side-by-side Compose and Kubernetes files, short fades between scenes, a whoosh on each cut (stronger on chapter
changes), an error tone when something breaks on screen and a chime when it is fixed or proven.

All music and sound effects are original and generated by code. [AUDIO-LICENSES.md](AUDIO-LICENSES.md) lists every
audio asset with its creator, source, license, attribution, and the timestamps where it plays (written by the build from
the real timeline).

## Files

| File | What it is |
|---|---|
| `scenes.py` | collects the chapters and adds the production layer (title card, end card, sound cues) |
| `scenes_1_intro.py` … `scenes_6_finish.py` | the script: scenes, narration steps and the visuals for each step |
| `scenes_common.py` | `S()` (a narration step, optional terminal zoom), `scene()`, real-file excerpts for code panels |
| `recordings.py` + `recordings/` | the recorded commands and outputs, and `rec()` to show them in a scene |
| `components.py` | building blocks: cards, tiles, diagrams, highlighted code, terminals |
| `build.py` | page → frames (with ease-in frames) → narration → encode → captions, chapters, description → post-production |
| `production.py` | title card, end card and the sound-effect cues |
| `audio_assets.py` | the original music bed and sound effects (synthesised; `python video/audio_assets.py preview` writes samples) |
| `redact.py` | removes identifying data from everything that reaches the video; the build fails if any remains |
| `shot.mjs`, `tts.ps1` | frame screenshots with headless Edge/Chrome; narration with the Windows speech engine |
| `thumbnail.html`, `youtube/` | thumbnail (1280×720) and upload package: titles, description with chapters, tags, captions, pinned comment |

## Build

Requirements: Windows (for `System.Speech`), Python 3 with `pygments`, `numpy` and `scipy`, Node.js 22+, Microsoft Edge
(or set `BROWSER`), and Docker (ffmpeg runs in a container pinned by digest).

```text
python3 tests/mdrun.py --record rec <lesson files>     # or download the run-* artifacts of the CI workflow
python video/recordings.py rec                         # copy the recordings the video uses into video/recordings/
python video/build.py                                  # → video/out/multi-stack-kubernetes-full.mp4 and -silent.mp4
```

`python video/build.py page` writes only the HTML page (open `out/page.html?sc=12&st=1` to see scene 12, step 1).
